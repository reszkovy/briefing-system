## Problem

Deep-linki UX kanibalizowały strony kategorii SEO, migracja omyłkowo ustawiła www jako primary (spadki w GSC/Senuto), 205 starych URL-i blogowych z arkusza SAMOSEO nie miało domu, a lab performance wynosił 52.

## Cel

Ochrona i odbudowa widoczności organicznej po migracji: uporządkowanie architektury URL, likwidacja kanibalizacji, pełne pokrycie historycznych adresów i poprawa Core Web Vitals.

Wdrożone — audyt zaleceń SEO 37/37 PASS (30.07.2026), performance desktop 52→94, archiwum 100% pokrycia starych URL-i; otwarte: 5 kategorii net-new bez stron standalone, walidacja formularza po stronie klienta
