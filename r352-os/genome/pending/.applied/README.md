# Pakiety już wdrożone

To archiwum, nie kolejka. `pending/` ma zawierać wyłącznie to, co czeka na podpis; pakiet
zostawiony tam po wdrożeniu wygląda jak praca do zrobienia i trafia do każdego skanu, który
przegląda kolejkę.

Nonce każdego z tych pakietów jest już zużyty w `.approval-nonces.jsonl`, więc ponowne
uruchomienie zostanie odrzucone jako replay. Trzymamy je dla prowieniencji, nie do użytku.

|---|---|---|---|
