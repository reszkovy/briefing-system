# Archiwum inboxa

Tu trafiają sygnały z werdyktem `ARCHIVE` albo `REJECT`. Przenosi je `/triage-signal`, nie Ty.

Nie kasujemy ich, bo „system już to wie" jest samo w sobie informacją: gdy ten sam sygnał
wraca trzeci raz, to znaczy, że wiedza istnieje, ale nie jest widoczna tam, gdzie jej szukasz.

Kropka w nazwie katalogu jest celowa — ta sama konwencja co `pending/.applied/`.
